# 食事予約自動化

Tampermonkey上で動作する、食事予約の自動化ユーザースクリプトです。

朝食はAを固定で予約し、昼食はメニュー内容を判定して、揚げ物をできるだけ避けるように予約します。

## 機能

### 朝食

朝食はメニュー内容に関係なく、常に **A予約** を選択します。

```text
朝食 → Ａ予約
```

### 昼食

昼食はA・Bのメインメニューを取得し、以下のルールで予約先を決定します。

#### 1. A・Bの両方が存在しない場合

メニューを正常に取得できなかった可能性があるため、**予約しません**。

```text
Aなし
Bなし
↓
予約しない
```

#### 2. 「白身魚」が含まれる場合

AまたはBのメインメニューに **「白身魚」** が含まれている場合、その日の昼食は**予約せず保留**します。

例えば、

```text
A 白身魚のフライ
B 豚肉の生姜焼き
```

の場合でも、

```text
→ 予約しない
```

となります。

「白身魚のフライ」「白身魚のムニエル」「白身魚のソテー」など、**「白身魚」という文字列を含むメニューはすべて対象**です。

#### 3. Bが揚げ物ではない場合

Bを予約します。

```text
A カツ丼
B 豚肉の生姜焼き
↓
Ｂ予約
```

#### 4. Bが揚げ物、Aが揚げ物ではない場合

Aを予約します。

```text
A 豚肉の生姜焼き
B チキンカツ
↓
Ａ予約
```

#### 5. A・Bの両方が揚げ物の場合

Aに鶏肉系のメニューがあれば、Aを優先します。

```text
A チキンカツ
B 豚カツ
↓
Ａ予約
```

Aにも鶏肉系がなければBを予約します。

```text
A 豚カツ
B 牛肉コロッケ
↓
Ｂ予約
```

## 判定ワード

### 揚げ物

以下の文字列を含むメニューを揚げ物として判定します。

```text
カツ
フライ
唐揚げ
からあげ
コロッケ
天ぷら
フリッター
竜田揚げ
```

### 鶏肉

両方が揚げ物だった場合の優先判定に使用します。

```text
チキン
鶏肉
若鶏
鶏
```

### 保留

以下の文字列を含む場合、昼食予約を行いません。

```text
白身魚
```

## 判定フロー

昼食の場合、以下の順番で判定します。

```text
             ┌─ A/B両方なし ─────→ 予約しない
             │
昼食 ────────┼─ 「白身魚」あり ──→ 予約しない
             │
             ├─ Bが揚げ物でない ─→ B予約
             │
             ├─ Bが揚げ物
             │    └ Aは揚げ物でない → A予約
             │
             └─ A/B両方揚げ物
                  ├─ Aが鶏肉系 → A予約
                  └─ その他 → B予約
```

## 動作対象

以下のページで動作します。

```text
https://rieils.gif.jp/*
```

Tampermonkeyにスクリプトを登録すると、対象ページ内の予約フォームを自動的に検出します。

## 予約実行

予約対象が決定すると、該当する予約ボタンを**800ms後に自動クリック**します。

コンソールには以下のようなログが出力されます。

```text
予約実行: 朝予約 Ａ予約
予約実行: 昼予約 Ｂ予約
```

白身魚などで保留された場合は、

```text
白身魚メニューのため昼食予約を保留:
```

とコンソールに表示されます。

## 注意事項

このスクリプトはメニューに含まれる文字列を単純に検索して判定しています。

そのため、メニュー表の表記が変更された場合や、想定していない表現が使用された場合には、正しく判定できない可能性があります。

また、**メニューを取得できなかった場合は安全側に倒して予約を行わない**仕様になっています。

---

### 現在の仕様まとめ

| 食事 | 条件              | 動作    |
| -- | --------------- | ----- |
| 朝食 | 常に              | A予約   |
| 昼食 | A・Bともに存在しない     | 予約しない |
| 昼食 | A/Bのどちらかに「白身魚」  | 予約しない |
| 昼食 | Bが揚げ物ではない       | B予約   |
| 昼食 | Bが揚げ物・Aが揚げ物ではない | A予約   |
| 昼食 | 両方揚げ物・Aが鶏肉系     | A予約   |
| 昼食 | 両方揚げ物・Aが鶏肉系ではない | B予約   |
